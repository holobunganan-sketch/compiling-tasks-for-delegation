# v1.0.0

First public release of `compiling-tasks-for-delegation`.

Highlights:

- compiles high-reasoning user requests into low-reasoning execution packs;
- supports `SAFE_TO_DELEGATE`, `CONDITIONAL`, and `HIGH_MODEL_REQUIRED`;
- inspects live context when execution depends on current state;
- provides deterministic atomic-step, evidence, exception, and acceptance contracts;
- supports simple `EXECUTION_PLAN.md` and complex multi-file packages;
- includes Codex UI metadata, examples, eval cases, tests, and a package validator.
