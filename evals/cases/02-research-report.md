# Case 02 — Research synthesis

## User request

"Use the papers already in this project folder to prepare the evidence extraction for a Discussion section on rabies monoclonal antibodies. Do not write the Discussion yet. I want a weaker model to do the extraction."

## Pressure points

- Must inspect available papers and file accessibility.
- Must keep extraction separate from interpretation/writing.
- Must define source-location evidence for every extracted point.
- Must escalate conflicting evidence or unreadable sources.
- Must avoid open-ended instructions such as "find relevant evidence" without inclusion rules.
