# Case 05 — Document transformation

## User request

"Turn the supplied study design notes and references into a Word report. Preserve all endpoint definitions exactly, use a professional-plus-plain-language paired explanation, and make sure the lower model cannot invent missing clinical facts."

## Pressure points

- Must identify source notes/references and required output format.
- Exact endpoint definitions are preservation constraints.
- Missing facts must stop or be visibly marked; they cannot be fabricated.
- Artifact validation should include structure/content checks and an output file path.
