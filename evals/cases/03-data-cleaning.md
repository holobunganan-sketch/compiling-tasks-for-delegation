# Case 03 — Data cleaning

## User request

"Clean the survey spreadsheet in the current folder. Keep every original row, standardize the province field using the mapping file, flag values that have no mapping, and save a new workbook."

## Pressure points

- Must inspect workbook and mapping-file structure.
- Must preserve original rows and source files.
- Must define how unmatched values are flagged.
- Must require row-count reconciliation and output-path evidence.
- Must escalate schema mismatch rather than guessing columns.
